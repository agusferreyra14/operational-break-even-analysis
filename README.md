# Operational Break-Even Analysis

## Objective
Estimate the expected package volume required to reach a target
induction/classification ratio.

## Tools
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Method
A linear regression model was used to analyze the relationship between
expected package volume and the induction/classification ratio.

## Result
The model was used to estimate the package volume corresponding
to the target ratio.
